# Assignment15

An Android application demonstrating the use of Google Maps and location-based services.

## Project Overview

This is a native Android application built with Gradle, featuring Google Maps integration and Play Services support.

## Features

- Google Maps integration
- Android Support Library (v7 AppCompat)
- Multi-DEX enabled for enhanced method count support
- Material Design compatible UI

## Technical Details

- **Min SDK:** 10
- **Target SDK:** 24
- **Build Tools Version:** 24.0.3
- **Key Dependencies:**
  - Google Play Services 9.6.1
  - Android Support AppCompat v7 24.2.1

## Building the Project

```bash
cd FifteenthAssignment
./gradlew build
```

## Running the Application

```bash
./gradlew installDebug
```

## Project Structure

- `app/` - Main application module
- `app/src/main/` - Application source code and resources
- `app/src/main/res/` - Resource files (layouts, drawables, values)

## Requirements

- Android Studio
- JDK 7 or higher
- Android SDK (API level 24 and above)
- Gradle
